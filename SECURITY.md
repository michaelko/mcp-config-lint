# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for vulnerabilities that could expose users. Email the maintainer or use GitHub private vulnerability reporting if it is enabled on the repository.

Include:

- Affected version or commit.
- Reproduction steps.
- Expected and actual behavior.
- Potential impact.

## Scope

This project is a static config linter. Reports about missed risky patterns, false negatives, unsafe output handling, or supply-chain issues are in scope.
